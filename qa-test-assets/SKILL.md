# 生成测试资源

根据当前对话中已编写或用户指定的测试用例，准备所需图片、视频和音频等输入文件，交付一个可下载的ZIP。默认只做本地素材准备，不执行产品用例。

## 确定素材需求

- 优先读取当前对话最近确认的用例及其真实Excel文件；已有用例明确时直接开始，不重复索要。多个版本会影响素材要求时，先核实版本。没有用例或无法确定素材需求时才询问。
- 从输入数据、前置条件和操作步骤提取：素材内容、数量、文件名、格式、尺寸、时长、帧率、音轨、文件大小和必要状态。以当前用例及需求为依据，不套用某个历史PR的机器人、4秒视频等固定素材。
- 只生成所需数量。同一素材能满足多条用例时共用；需要不同内容、不同状态或独立输入时保留区别。不能用同图改名充当多张不同内容的图片；仅用例命名确需别名时提供副本。
- 用例指定文件名时尽量保持原名；否则使用能区分内容及关键条件的短文件名，如`walk_audio_4s.mp4`、`silent_4s.mp4`、`too_short_3s.mp4`。不额外修改用例Excel。

## 生成媒体

- 图片需要角色、照片或具体视觉内容时，使用当前可用的imagegen技能及其工具；简单几何测试图、色块、图表等可用确定性绘制。遵循相关工具的生成、编辑和保存要求。
- 视频必须符合用例要求的实际画面与运动。人物行走、挥手、镜头移动等要在视频中真实可见，不能拿静态图片循环冒充。要求真人、自然场景、口型、多个主体或复杂动作时，不以不符合条件的简单动画凑数；缺少生成能力时如实说明具体缺口。
- 用户只要求动作或上传素材、没有写实要求时，可制作合适的合成动画；在聊天中简短说明其类型。音频可按要求合成或使用有权复用的素材；要求脚步声、语音、音乐时不能用任意提示音代替。
- 分清“无音轨”和“有音轨但静音”；有声文件应检查实际有可听信号。视频中的声音与独立音频文件按用例分别准备，不为凑分类额外导出无需求的音频。
- 有大小或时长边界时按用例精确生成并核对。普通媒体保持可播放；格式错误、损坏等异常文件仅在相应用例明确要求时制作。
- 文件大小限制测试可采用符合格式规范的填充区块，但必须能完整解码，且实际文件大小满足边界；在聊天中说明采用填充及解压后占用。涉及码率、真实内容体积或传输表现时，不以填充替代相应要求。
- 已保存角色、产品生成历史、账号权限、会员状态和“已确认被审核拦截”等条件不是本地文件属性。准备能提供的媒体，将尚需产品内准备或确认的条件简短列在聊天中，不伪造账号数据或把未验证图片标作审核必拦截素材。
- 本技能默认不登录产品、上传素材、创建站内角色、生成站内记录、扣站内积分或修改权限。用户另外授权产品内准备时遵循该任务和工作区约定；本地文件仍不能冒充产品内成品。

## 检查与打包

- 图片验证实际格式、可读取性及所需尺寸；检查内容和必要区别。
- 视频及音频核对实际格式、编码、时长、尺寸、帧率、音轨及文件大小，并完成解码检查。根据用例检查关键帧和音频信号，不能仅凭扩展名或生成命令宣称满足条件。
- 不符合要求的素材先修正再打包。仍有缺口时交付已完成的可用素材，在聊天中明确未提供的项目及原因，不宣称全部前置条件齐备。
- ZIP以任务名和用户本地日期命名，例如`PR5348_测试资源_20261106.zip`。在本次对话可写输出目录中创建；不要覆盖先前交付，后续版本使用新名称。
- 按实际需要的媒体类别建立文件夹，名称固定为`图片`、`视频`、`音频`；不需要的类别不建立空文件夹。其他明确需要的输入文件采用对应类别文件夹。不要按用例重复复制整套素材。
- **压缩包内仅包含类别文件夹及测试输入文件。不得加入使用说明、README、预览、缩略图、联系表、JSON、清单、校验文件、脚本、日志、报告或用例Excel。** 若JSON等本身是某条用例明确要求的输入文件，可作为该输入提供，不能借此加入辅助文件。
- 生成脚本、内部检查结果和临时预览如有需要可保留在独立工作目录，绝不混入交付ZIP。创建ZIP时显式选择素材，不压入整个工作目录或`.DS_Store`、`__MACOSX`等系统文件。
- 检查ZIP可解压、文件数量与分类符合需求、没有重复条目或非素材附件；核对解压后的大小边界仍满足条件。

## 交付

- 返回一个真实可点击的ZIP链接，简短说明图片、视频、音频数量及必要缺口即可。不额外交付说明、预览、JSON、脚本或报告链接，不在回复中展开逐文件使用说明。
- 说明本次只准备素材，未执行产品测试；如果用户同时要求执行，按其执行授权另行处理。
- 不主动重做之前已经交付的素材包；创建或更新本技能的请求只修改技能，用户之后说“生成测试资源”时才生成当次素材。
