# 中文功能测试用例

根据需求、PR 或提测任务，编写、补充或调整可从产品页面操作和验证的中文功能用例。

**使用**：提供需求或链接，说“编写测试用例”，或使用 `$qa-test-cases`。

**输出**：一个 `.xlsx`，固定七列：用例编号、用例标题、前置条件、输入数据、操作步骤、预期结果、优先级。以通俗产品语言覆盖有依据的流程、异常、边界及权限等场景。

**安装**：将本目录（包含 `references`）放入 `~/.codex/skills/`；Excel 生成需要环境提供 Spreadsheets 技能。

只编写用例，不执行测试，不输出接口用例，也不保证全部场景均可自动化。
